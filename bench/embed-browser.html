VORTEX embedder benchmark

Query parameters: devices=webgpu dtypes=q4 runs=3 threads=N wasm=cdn local=1. The reference build is pinned q4 at a fixed model revision with the reference prompt and truncation; any other dtype is an alternate build, not reference namespace acceptance. Default is one backend per fresh page (webgpu when an adapter is present, else wasm); an explicit devices= list is still honored, but the first load/warmup/inference failure stops the run and later rows are marked SKIPPED/NOT ATTEMPTED — reload a fresh page per backend instead. The installed inference-session factory chains backend init without recovering a rejection, so repeated errors in one page are not independent provider evidence and there is no automatic runtime fallback. Without local=1 the first visit downloads the pinned model from Hugging Face. With local=1 the original installed cache under node_modules/@huggingface/transformers/.cache is served same-origin by the existing bench server; remote downloads and the browser model cache are then disabled.
