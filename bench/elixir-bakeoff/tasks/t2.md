# Task 2

Write `lib/bakeoff/t2/ring.ex` defining the struct `Bakeoff.T2.Ring` so that `mix test test/t2_test.exs` passes. Do not edit the test file.

A ring holds the newest `capacity` items pushed into it.

* `Ring.new(capacity)` returns an empty ring. It raises `ArgumentError` unless the capacity is a positive integer.
* `Ring.push(ring, item)` adds an item, dropping the oldest one when the ring is full.
* A ring is `Enumerable`, oldest item first, and reports its size without walking its items.
* A ring is `Collectable`: collecting into a ring pushes each item.
* A ring inspects as `#Ring<[2, 3, 4]>`, respecting the usual inspect options.
* Pushing must stay cheap when the ring is large.
