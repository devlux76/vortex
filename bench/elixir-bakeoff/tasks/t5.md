# Task 5

Write `lib/bakeoff/t5.ex` defining `Bakeoff.T5` so that `mix test test/t5_test.exs` passes. Do not edit the test file.

`use Bakeoff.T5` gives a module the macro `defevent`:

```elixir
defmodule Mail do
  use Bakeoff.T5

  defevent :mail_stored, [:owner, :room]
  defevent :acted
end
```

For each event the module gets:

* A constructor named after the event, taking the fields in order: `Mail.mail_stored("claude", "r1")` returns `%{event: "mail.stored", owner: "claude", room: "r1"}`. The `event` value is the name with underscores turned into dots.
* An entry in `__events__/0`, a keyword list of name and arity sorted by name.
* A clause of `decode/1`, which takes a map with string keys, as decoded from JSON, and returns `{:ok, event}` with atom keys and unknown keys dropped, or `:error`. It must not create atoms from its input.

These are compile errors (`CompileError`, with a message naming the problem): declaring the same event twice, a field called `event`, a repeated field, and a name or field that is not an atom.

Any atom must work as a field name.
