# Task 1

Write `lib/bakeoff/t1.ex` defining `Bakeoff.T1` so that `mix test test/t1_test.exs` passes. Do not edit the test file.

* `rle(string)` returns a list of `{character, count}` for each run of equal characters, in order. A character is a grapheme: what a reader sees as one character.
* `unrle(list)` reverses `rle/1`.
* `frames(binary)` splits a buffer into frames. A frame is a 16-bit big-endian length followed by that many bytes of payload. It returns `{payloads, rest}`, where `rest` is whatever follows the last complete frame.
* `flatten(map)` turns a nested map with string keys into a flat map whose keys are the paths joined with `"."`. An empty map, a struct and a list are values, not levels to descend into.
