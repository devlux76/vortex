# Task 6

`lib/bakeoff/t6/rate_limiter.ex` is a token bucket that does not work. Fix it so that `mix test test/t6_test.exs` passes. Do not edit the test file. The public functions keep their names and arguments.

What it is meant to do:

* It starts full, with `capacity` tokens, and gains one token every `refill_ms` milliseconds, never holding more than `capacity`.
* `take(pid, n)` takes `n` tokens and returns `:ok`, or takes nothing and returns `{:error, :empty}`.
* `tokens(pid)` returns how many it holds.
* `wait(pid, timeout)` takes one token, waiting up to `timeout` milliseconds for one, and returns `:ok` or `{:error, :timeout}`. Waiters are served one per refill, in the order they arrived. A waiter that gave up is no longer in line and uses no token.

There are several bugs. Before changing the file, say what each one is.
