# Task 4

Write `lib/bakeoff/t4.ex` (and more files if you want them) defining `Bakeoff.T4` so that `mix test test/t4_test.exs` passes. Do not edit the test file.

`Bakeoff.T4` is a supervision tree of named counters. It is started as a child, `{Bakeoff.T4, []}` or just `Bakeoff.T4`, and contains a `Registry` registered as `Bakeoff.T4.Registry`.

* `start_counter(name)` starts a counter at zero and returns `{:ok, pid}`, or `{:error, :already_started}`.
* `incr(name)` adds one and returns the new value. `value(name)` returns the value.
* `stop_counter(name)` stops a counter for good and returns `:ok`.
* `whereis(name)` returns the counter's pid or `nil`. `counters()` returns the names, sorted.
* `incr/1`, `value/1` and `stop_counter/1` return `{:error, :not_found}` for a name that is not running.

Behaviour under failure:

* A counter that crashes is restarted under the same name, starting from zero.
* A counter that crashes many times in a row must not affect any other counter.
* If the registry dies, all counters are stopped and the tree carries on empty, ready for new counters. The top supervisor itself does not die.
