# Task 3

Write `lib/bakeoff/t3/debounce.ex` defining the GenServer `Bakeoff.T3.Debounce` so that `mix test test/t3_test.exs` passes. Do not edit the test file.

A debouncer holds back a value until things have been quiet for a while.

* `Debounce.start_link(fun: fun, delay: ms)` starts it. It must also work as a child spec: `{Debounce, fun: fun, delay: ms}`.
* `Debounce.put(pid, value)` returns `:ok`. `fun.(value)` is called once `delay` milliseconds have passed with no further `put`. Each `put` replaces the pending value and restarts the delay.
* `Debounce.flush(pid)` calls the function with the pending value, if there is one, before it returns `:ok`, and cancels the delay.
* `Debounce.pending?(pid)` says whether a value is waiting.
* If the function raises, the server keeps running.

Use one-shot timers. A timer that was replaced or cancelled must never cause a call, even if its message was already on the way.
